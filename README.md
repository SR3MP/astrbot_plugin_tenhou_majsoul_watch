天凤 / 雀魂 云观战插件
===

安装
---
AstrBot 插件市场搜索「天凤/雀魂云观战」，或将仓库 `git clone` / 下载到 `data/plugins/` 后重启：

```
data/plugins/astrbot_plugin_tenhou_majsoul_watch/
```

安装后在群内发送 `wghelp` 查看全部指令；雀魂账号可选，不配置时天凤全部功能与雀魂 `mspt` 昵称查询仍可用。

指令
---
```
wg                       列出进行中对局
wg <四位码>              跟踪天凤对局
wg m<四位码>             跟踪雀魂对局
wg <WG码|大厅码|玩家名>  跟踪天凤对局
wg <雀魂UUID>            跟踪雀魂对局
wg- [码]                 取消跟踪
wgon / wgoff [0|1|2]     自动播报开关 1=天凤 2=雀魂 0=两者
wginfo [码]              查当前比分
wgstat                   查本群订阅与跟踪状态
wgls                     查订阅列表
wghelp                   查指令用法
wglog <牌谱码|链接>      查天凤牌谱

thadd <玩家名>           订阅天凤玩家
thdel <玩家名>           取消订阅天凤玩家
thfilter [场...]         只播报指定天凤场，all 清空

msadd <AID|昵称|$AID>    订阅雀魂玩家
msdel <AID|昵称|$AID>    取消订阅雀魂玩家
msfilter [场...]         只播报指定雀魂场，all 清空
mspt <AID|昵称|$AID>     查雀魂段位和 PT
msls [场名|比赛号]       列出雀魂可跟踪对局
```

四位对局码
---
每场对局对应一个四位码，由对局 ID 的 md5 取前 4 位（十六进制，小写显示）：天凤用 8 位 WG 码计算，
显示成 `#a1b2`；雀魂用对局 uuid 计算，带 `m` 前缀显示成 `#ma1b2`。群内任何成员发送 `wg a1b2`
（天凤）或 `wg ma1b2`（雀魂）即开始播报该场。

- 同一场对局在任何群、任何时间都是同一个码，可跨群复用
- `m` 前缀区分平台：`wg m…` 只匹配雀魂，`wg ` 后接 4 位十六进制只匹配天凤
- 4 位纯数字先按天凤对局码查询，无结果再按数字房号处理；带字母的码始终按大厅处理
- 四位码共 65536 个取值，同一平台同时进行的数百场之间存在撞码可能；命中多场时列出完整 WG 码 / uuid 要求指定
- 该场已在跟踪（本群已播过开局，或指令重复发送）时，回显只有一行开启提示，开局播报不重复输出

天凤大厅码形如 `L0001`（一般桌）或 `C` + 4 位大厅 + 4 位规则（对战房），也可直接使用数字房号。
天凤牌谱码形如 `2024010100gm-0000-0000-00000000`，`wglog` 也可直接接受完整链接。
雀魂比赛场默认只列当前账号参加或关注的比赛，`msls <比赛号>` 可指定其他比赛。

牌面记法
---
两个平台同一套 mspz 记法：万 m / 筒 p / 索 s / 字牌 z，字牌用 `1z`–`7z`
（1东 2南 3西 4北 5白 6发 7中），赤 5 记 `0`，手牌行和副露行都按此写。

- 排序存在一处差异：天凤手牌和副露都把赤 5 排在 5 的位置（`340s`），雀魂两行都按字符排序、赤 5 在最前（`055s`）
- 三人场的拔北记在副露行末（`拔北×n`），四人场没有这一段，两个平台同一口径

使用限制
---
- 标题时间取服务端推送该条消息的时刻；回放一律不留时间位，不补充时间
- 实时观战延迟约 5 分钟，两个平台相同；新开对局的开始阶段收不到推送属正常
- 雀魂实时观战依赖雀魂登录态，未登录无法观战
- `mspt` / `msadd` 未登录时按昵称走牌谱屋精确匹配，重名会列出候选（牌谱屋不带服务器字段，可能含非国服账号），需改用 `mspt $AID`；四麻查无记录时该行写 `? 0`
- 雀魂直播列表只保留最近 100 局，开局约 4 分钟后即查不到该场，所以订阅需在该玩家开局之前生效。
  已订阅账号不受影响：开局后插件自动为该场挂观战流，用仍在局表中的完整 uuid 逐局播报
- 雀魂段位场码散场后查询不到；比赛场带牌谱索引，终局后仍可 `wg` 进入回放
- 天凤对局结束后牌流消失、四位码查询不到，改用 `wglog <牌谱码>` 查看完整牌谱
- 雀魂玩家的段位、分数与五个率按账号缓存 20 分钟；五个率只播段位场，比赛场没有对应的资料页，整段不输出
- 天凤段位房列表不含点数，当前 PT 服务端也不下发，所以只有段位和 R
- 段位场场名（银/金/玉/王座）优先取列表行自带的字段，缺失时按各家最高段位推断；段位房允许相邻段位
  同桌，此时场名可能偏低。雀魂比赛全名过长，播报只取段位组那一段
- 重连后天凤会补发本场历史、雀魂会重推整场，按局号与本场序号去重，只输出未播过的小局
- 服务端未下发的字段整段省略，或用一行 `注:` 说明缺失项，不推算补齐
- `thadd` / `msadd` 只登记订阅玩家和开局/散场推送；逐局播报需显式 `wg` 开启，重启插件不恢复跟踪

雀魂配置
---
在 AstrBot 插件配置（WebUI 或 `_conf_schema.json`）中填写：
```json
{
  "majsoul": {
    "email": "your@email.com",
    "password": "your_password",
    "token": "",
    "poll_interval": 30
  }
}
```
- email/password：雀魂登录凭证（推荐）
- token：已有的 access_token，填写后跳过账号密码登录
- poll_interval：后台监控订阅玩家对局的轮询间隔（秒），默认 30，最低 15
- 未配置雀魂账号时 `mspt` 无法按 AID 查询（按昵称仍可用），`msadd` 能登记 AID 但监控不到对局；其余指令不受影响

依赖
---
- `requirements.txt` 只含 `websockets`（AstrBot 已内置，不会额外拉包）
- `ms/protocol_pb2.py` 和 `ms/rpc.py` 是雀魂客户端协议（`protocol.proto`）的生成产物，插件不手写这两个文件
- 运行时在插件目录生成 `sub_state.json`（订阅状态），`.gitignore` 已排除，不应提交
