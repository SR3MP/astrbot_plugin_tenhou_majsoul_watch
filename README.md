天凤 / 雀魂 云观战插件
===

安装
---
AstrBot 插件市场搜索「天凤/雀魂云观战」，或将仓库 `git clone` / 下载到 `data/plugins/` 后重启：

```
data/plugins/astrbot_plugin_tenhou_majsoul_watch/
```

安装后在群内发送 `wghelp` 查看全部指令；天凤全部功能免配置。雀魂监控对局需要填写账号；昵称查询另有牌谱屋匿名回退，未填账号时仍可用（见「雀魂配置」）。

WebUI 管理页
---
AstrBot 内置 Dashboard 侧栏的「天凤/雀魂云观战」页面提供五个页签：状态总览、订阅管理、定制文案、PT 报告、插件配置。所有页签按群（session）切换，订阅、筛选、开关和群指令共用同一份状态；配置页中密码/token 打码显示，留空表示不改动。

指令
---
```
wg                       列出进行中对局
wg <四位码>              跟踪天凤对局
wg m<四位码>             跟踪雀魂对局
wg <WG码|大厅码|玩家名>  跟踪天凤对局
wg <雀魂UUID>            跟踪雀魂对局
wg- [码]                 取消跟踪
wgon / wgoff [0|1|2]     自动播报开关 1=天凤 2=雀魂 0=两者
wginfo [码]              查当前比分
wgstat                   查本群订阅与跟踪状态（仅本群对局，附全局观战容量）
wgls                     查订阅列表
wghelp                   查指令用法
wglog <牌谱码|链接>      查天凤牌谱

thadd <玩家名>           订阅天凤玩家
thdel <玩家名>           取消订阅天凤玩家
thfilter [场...]         只播报指定天凤场，all 清空

msadd <AID|昵称|$AID>    订阅雀魂玩家
msdel <AID|昵称|$AID>    取消订阅雀魂玩家
msfilter [场...]         只播报指定雀魂场，all 清空
mspt <AID|昵称|$AID>     查雀魂段位和 PT
msls [场名|比赛号]       列出雀魂可跟踪对局，带比赛号时自动登记该场比赛
msaddc <比赛号>          登记比赛场，wg 可跟踪、订阅玩家在该场开局播报
msdelc <比赛号>          取消登记比赛场

ctset <玩家名> [节点] <文案>  设定制文案；节点 start/round/big/finish，省略为 finish
ctdel <玩家名> [节点]        删定制文案（省略节点删全部）
ctl                          列出本群定制文案
report                       生成本群 PT 日/周/月图片榜
```

`wgstat` 的「进行中对局」「自动观战流」按本群订阅玩家/账号过滤，只显示本群命中的对局；`全局 N/8` 是服务器总观战容量，不代表本群。播报正文的开局主角名单、终局顺位点评和大牌通报同样只按本群订阅玩家生成；四家座位、段位与分数是公开对局信息，不受群隔离影响。

四位对局码
---
每场对局对应一个四位码，由对局 ID 的 md5 取前 4 位（十六进制，小写显示）：天凤用 8 位 WG 码计算，
显示成 `#a1b2`；雀魂用对局 uuid 计算，带 `m` 前缀显示成 `#ma1b2`。群内任何成员发送 `wg a1b2`
（天凤）或 `wg ma1b2`（雀魂）即开始播报该场。

- 同一场对局在任何群、任何时间都是同一个码，可跨群复用
- `m` 前缀区分平台：`wg m…` 只匹配雀魂，`wg ` 后接 4 位十六进制只匹配天凤
- 4 位纯数字先按天凤对局码查询，无结果再按数字房号处理；带字母的码始终按大厅处理
- 四位码共 65536 个取值，同一平台同时进行的数百场之间存在撞码可能；命中多场时列出完整 WG 码 / uuid 要求指定
- 该场已在跟踪（本群已播过开局，或指令重复发送）时，回显只有一行开启提示，开局播报不重复输出

天凤大厅码形如 `L0001`（一般桌）或 `C` + 4 位大厅 + 4 位规则（对战房），也可直接使用数字房号。
天凤牌谱码形如 `2024010100gm-0000-0000-00000000`，`wglog` 也可直接接受完整链接。
雀魂比赛场默认只列当前账号参加或关注的比赛，`msls <比赛号>` 可指定其他比赛。

牌面记法
---
两个平台同一套 mspz 记法：万 m / 筒 p / 索 s / 字牌 z，字牌用 `1z`–`7z`
（1东 2南 3西 4北 5白 6发 7中），赤 5 记 `0`，手牌行和副露行都按此写。

播报显示增强
---
在插件配置 `display` 分组设置，保持默认时播报格式不变。

- `rate_source`：五率数据来源。`majsoul`（默认）用雀魂官方统计；`sapk` 用牌谱屋统计，并在段位后追加 `|场数战`（如 `雀豪一 2181/2800|29战`），玉/王座场（含东风场与三麻）再追加 `|安定位`（如 `|安豪-1.83`）。场数、五率与安定都按当前对局所在的场统计，东风/半庄、三麻/四麻各算各的（三麻走牌谱屋三人数据与三麻 delta），不会把其他场累加。牌谱屋只收录金/玉/王座，银、铜、初心与比赛场不显示场次，金之间不显示安定（与牌谱屋一致）。牌谱屋查不到时保留雀魂数据，不补数。
- `tier_labels`：安定标签开关，仅 `sapk` 生效。开启后按 `tiers` 中的区间匹配安定段位，在名字后追加命中的标签（如 `选手A|高手 雀豪一…`）。区间为左闭右开 `[min, max)`，上下限留空表示不限，按顺序取首个命中的标签。上下限填安定数值：雀豪一=1、雀豪二=2、雀豪三=3、雀圣一=4、雀圣二=5、雀圣三=6，每升一阶 +1；可填小数（如 1.5），负值表示雀豪一以下。
- `sanhaoyi_image`：雀豪彩蛋开关。开启后，对局开始时若恰好三家雀豪一，在该条播报后单独发一张图片。
- `point_alert`：大牌文案开关。开启后，自动播报（未 `wg`）的对局中，被订阅玩家和牌或放铳点数命中 `point_rules` 时发送对应文案；需显式 `wg` 的跟踪流不触发。
- `point_rules`：大牌文案规则列表。每条含 `type`（和出/点出/两者）、点数下限 `min`、上限 `max`、文案 `text`；区间同为左闭右开，上下限留空不限，可配置多条。

定制文案
---
按「群 + 玩家 + 节点」覆盖播报内容，写入即生效，不重启。节点：`start`（对局开始）、`round`（小局结算/流局）、`big`（大牌通报）、`finish`（对局完成）；`ctset` 省略节点时按旧版只改终局点评行。`big` 按和出/点出与点数区间分档，`finish` 可先按名次分档。

模板支持整条重写，也可只写一句替换终局点评行。常用占位符：`{name}` 玩家名、`{mid}` 四位码、`{time}` 时间、`{kind}` 和出/点出、`{gain}` 点数、`{desc}` 和牌描述、`{mood}` 文案心情、`{hule}` 和牌行、`{head}` 首行、`{raw}` 原样整条，另有 `{game}` `{place}` `{score}` `{pt}` `{lines}` 等；WebUI「定制文案」页有逐节点完整说明与例子。大牌通报只走自动播报流，显式 `wg` 跟踪不触发。

PT 报告
---
配置 `report.enabled=true` 后，每天 `hour:minute`（容器本地时间）按各群订阅账号推送一张图片表格：日报每天发，周报周一、月报每月 1 号随日报一起发。手动 `report` 或 WebUI「PT 报告 → 生成」只统计当前群账号。段位晋升按全局累计 PT 折算显示涨幅并标 `↑段位`，不再显示为暴跌。

使用限制
---
- 实时观战延迟约 5 分钟，两个平台相同
- 雀魂段位场码散场后查询不到；比赛场终局后仍可 `wg` 进入回放
- 天凤对局结束后四位码查询不到，改用 `wglog <牌谱码>` 查看完整牌谱
- 按昵称查雀魂玩家按 自己 → 官方 RPC → 牌谱屋 → 实时观战列表 逐级回退，重名会列出候选；牌谱屋昵称反查与统计匿名可用，不需凭证
- 牌谱屋按出口 IP 限流时昵称查询可能返回 `429 x-cap-token-required`，可换网络重试；`koromo.token` 只在限流时作为请求头带上，留空不影响正常情况下的昵称查询、统计与对局监控
- 逐局播报要显式 `wg` 开启；`thadd` / `msadd` 只订阅开局/散场推送，重启插件不恢复跟踪
- 订阅所在平台被停用或删除时，该会话的播报直接跳过并在日志提示一次，不再逐条重试；平台重新启用后自动恢复。重启加载期间平台实例尚未注册的会话仍按原逻辑等待重试
- QQ 官方机器人主动推送依赖最近一次群消息缓存的会话信息：重启后若该群无人发言，适配器会跳过发送（日志 `No cached msg_id for session`）。需群内有成员先发言，或在开放平台开通主动消息权限

雀魂配置
---
在 AstrBot 插件配置（WebUI 或 `_conf_schema.json`）中填写：
```json
{
  "report": {
    "enabled": false,
    "hour": 12,
    "minute": 0
  },
  "majsoul": {
    "email": "your@email.com",
    "password": "your_password",
    "token": "",
    "poll_interval": 30
  },
  "koromo": {
    "token": ""
  },
  "display": {
    "rate_source": "majsoul",
    "tier_labels": false,
    "tiers": [],
    "sanhaoyi_image": false,
    "point_alert": false,
    "point_rules": []
  }
}
```
- report：PT 定时报告；`enabled` 开启后按 `hour:minute` 推送，手动 `report` 不受开关限制
- email/password：雀魂登录凭证（推荐）
- token：已有的 access_token，填写后跳过账号密码登录
- poll_interval：后台监控订阅玩家对局的轮询间隔（秒），默认 30，最低 15
- koromo.token：牌谱屋访问凭证（可选）。仅在出口 IP 被限流时作为请求头带上；留空不影响正常情况下的昵称查询、统计与对局监控
- display：播报显示增强，逐项说明见「播报显示增强」。`tiers` / `point_rules` 在 WebUI 中以可增删的表单项填写，上下限留空即不限
- 未配置雀魂账号时 `mspt` 仍可按昵称查询（走牌谱屋），`msadd` 能登记 AID 但监控不到对局；其余指令不受影响
- 插件激活（含热重载）后自动登录一次，失败按 60 秒间隔重试 3 次，`wgls` / `wgstat` 可看登录态
